# 台灣電網最吃緊的日子，是「再生能源低谷」而非「用電尖峰」

一個用**完全開放的台電資料**做的、可重現的小分析。發現一件反直覺的事：
2025–2026 年，台灣電網備轉容量率最低（最吃緊）的日子，**由再生能源低谷（低風 × 低光）
主導，而不是尖峰用電需求**——而且和夏季用電尖峰**脫鉤**，集中在秋冬。

> 這是「相關性常被誤讀」的真實案例：直覺是「天氣熱 → 用電多 → 電網吃緊」，
> 但資料說主因是**再生能源低谷（VRE-drought）**。

![margin vs renewables](figures/fig1_margin_vs_renewables.png)

## 發現（2025-01 ～ 2026-05，516 天）

| | 最吃緊 15 天 | 全體平均 |
|---|---|---|
| 備轉容量率 | **7.8 %** | 19.7 % |
| 再生能源（風+光，萬瓩） | **170** | 524（只剩 1/3） |
| 尖峰負載（萬瓩） | 3310 | 3245（**只高一點**） |

- 備轉率 vs 再生能源 **r = +0.51**；vs 尖峰負載僅 **−0.12**
- 標準化迴歸（同時控制）：太陽能 **+0.97**、風力 +0.27、負載 −0.69 → **再生能源合計主導**
- 最吃緊的日子集中在 **9 月（15 天中 7 天）與 1 月** → 秋冬再生低谷，非夏季尖峰
- 條件備轉率：只有高負載 **18.6 %**、只有低再生 **12.1 %**（一般日 19.7 %）→ 低再生壓得更低

### 排除「歲修」confound

秋季備轉低，會不會只是電廠歲修（供給下降）而非再生低谷？分解供給後：
吃緊日是**供給短（−313 萬瓩）**而非需求高（+65）；而這個供給缺口 **113 % 由再生能源解釋**
（火力/核能在吃緊日反而更多）→ **歲修不是主因，就是再生低谷。**

## 為什麼重要

台灣 2025 年完成非核化、正大推光電與離岸風（2030 目標 31 GW 光電 / 13 GW 離岸風）。
本分析顯示：**在目前的高再生時代，壓垮備轉的已經是再生低谷、不是熱浪尖峰**，而且它
發生在需求只有中等的秋冬——這正是「淨負載尖峰 / VRE-drought」風險的在地證據，
對儲能佈署與備轉安排的時機有直接意涵。

## 資料來源（全開放）

| 資料 | 來源 | 內容 |
|---|---|---|
| 每日供需 + 風力/太陽能 | [data.gov.tw 19995](https://data.gov.tw/dataset/19995)（台電） | 尖峰負載、備轉率、風力、太陽能、各機組（2025 起） |
| 每日備轉容量率 | [data.gov.tw 24945](https://data.gov.tw/dataset/24945)（台電） | 備轉率（2023 起，序列較長） |

授權：政府資料開放授權條款。

## 誠實的限制

- **窗口短**：風力/太陽能的每日分項在開放資料中只到 2025 起（516 天），最吃緊只有 15 天樣本——
  是「當前高再生時代」的快照，不是長期氣候。
- **日總量、非尖峰瞬間值**：太陽能用日總量，沒抓到備轉最低那一刻的瞬時出力（鴨子曲線的時序未解析）。
  更嚴謹的版本應改用尖峰時刻的分項出力。
- **正逢光電暴衝年**：2025-26 光電快速成長，型態未來會演變；結論需隨年份更新。
- **新穎性**：VRE-drought / dunkelflaute 方法在歐美日已有；本專案的價值是**把它落地到台灣的開放電網
  資料、並得到一個具體且反直覺的在地發現**，而非方法創新。
